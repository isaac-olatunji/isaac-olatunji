## 🎬 Defining Success: A Multi-Dimensional Analysis of Movie Performance

A Power BI analysis of 1.4M+ movie records exploring what makes a film successful across audience reception, engagement, and financial performance — culminating in a Success Matrix that evaluates performance across all three dimensions.

### Highlights

- 1.4M+ movie records cleaned and modelled in Power Query
- Multi-dimensional analytical framework: audience reception, engagement, and financial performance
- Financially reliable ROI population introduced to prevent distortion from extreme outliers
- Median-based KPIs used where distributions are heavily right-skewed
- Four-page data-storytelling dashboard with insight banners and editorial narrative
- Success Matrix classifying films across four performance quadrants
- Competition submission — Power BI DataViz World Championships Final Round

**Tools:** Power BI · Power Query · DAX

## 🛒 Olist Marketplace Performance Analysis

End-to-end e-commerce analytics project transforming the Brazilian Olist marketplace dataset through MySQL data engineering and a Kimball-inspired star schema — delivering a five-page Power BI dashboard that analyses sales performance, product and customer behaviour, seller contribution, delivery efficiency, and customer satisfaction.

### Highlights

- MySQL data engineering: 1.5M+ records across 9 source files
- Star schema redesign — identified and resolved row multiplication problem from multiple one-to-many joins
- Kimball-inspired dimensional model: Fact Sales, Dim Customer, Dim Product, Dim Seller, Dim Date
- Payment and review aggregation to order level before joining to fact table
- Five-page interactive dashboard with cross-filter scenario analysis
- Two analytical scenarios: problem investigation vs performance investigation

**Tools:** MySQL · SQL Server · Power BI · Power Query · DAX

🔗 [View Project Repository](https://github.com/isaac-olatunji/Olist-Marketplace-Performance-Analysis)
